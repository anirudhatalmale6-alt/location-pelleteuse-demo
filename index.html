Ces 19 pages ne sont pas encore sur location-pelleteuse.fr — je n'ai pas l'acces FTP. Elles tournent ici pour que vous puissiez les essayer pour de vrai, avant de decider.

L'habillage (couleurs, logo, menu) est charge depuis votre site : c'est exactement ce que vous verrez une fois les pages en ligne.

A essayer en premier
  1. Ouvrez une page departement ci-dessous, tapez livry dans le moteur : il propose Livry-Gargan et Livry-sur-Seine.
  2. Tapez un code postal, par exemple 77500 : il trouve Chelles.
  3. Tapez Dourdan : cette commune n'a pas encore de page, vous arrivez sur la page de l'Essonne avec le bandeau « Vous cherchiez Dourdan (91410) ».
  4. Sur telephone, la barre d'appel reste collee en bas de l'ecran.
