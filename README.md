# Demonstration — location-pelleteuse.fr

Apercu en ligne des pages generees : moteur de recherche par departement et
par commune, pages departement, pages commune, formulaire de devis.

Ces pages ne sont pas encore publiees sur le site definitif. Elles sont ici
pour etre essayees avant mise en ligne.

L'habillage (feuilles de style, images, polices) est charge depuis
location-pelleteuse.fr : **aucun fichier du theme n'est redistribue ici**.

Toutes les pages portent `noindex,nofollow` et une balise canonique vers le
site reel, pour qu'aucune ne concurrence celui-ci dans Google.

Donnees des communes : geo.api.gouv.fr (source officielle).
